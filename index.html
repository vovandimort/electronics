Що таке скетч?

Програма для Arduino називається скетч. Плата не вміє «думати» сама — вона виконує команди, які ми записали. Кожен скетч складається з двох обов’язкових частин:

setup() — «підготовка»

Виконується один раз при вмиканні або натисканні Reset. Тут налаштовуємо піни: що вхід, що вихід.

loop() — «основна робота»

Після setup() виконується знову і знову, без кінця, поки є живлення. Це серце програми.

💡 Уяви ранок: setup() — прокинутись і зібрати рюкзак (раз), loop() — уроки, які повторюються щодня.

▶ Виконай програму крок за кроком

Натискай «Крок» — підсвічується рядок, який Arduino виконує зараз. Зверни увагу: setup() спрацює лише раз, а loop() крутиться по колу.

void setup() {  pinMode(13, OUTPUT);}void loop() {  digitalWrite(13, HIGH);  delay(1000);  digitalWrite(13, LOW);  delay(1000);}
Натисни «Крок», щоб почати.

setup() виконано: 0 раз · loop() повторів: 0

🔧 Експериментуй із delay()

Рухай повзунок — змінюється код і швидкість блимання. Потім вимкни pinMode і побачиш, що буде.
















Кнопка і проблема «плаваючого» входу


Щоб Arduino «відчула» кнопку, пін має бути INPUT, а ми читаємо його через digitalRead(). Але якщо пін ні до чого не підключений (кнопка відпущена), він ловить наводки з повітря і видає випадкові HIGH/LOW. Це називається плаваючий вхід. Лікування — резистор, який «тягне» пін до певного рівня:


    

  • Pull-down (підтяжка до землі) — резистор до GND. Кнопка відпущена → LOW, натиснута → HIGH.
    • 

  • Pull-up (підтяжка до живлення) — резистор до 5 В. Кнопка відпущена → HIGH, натиснута → LOW (логіка інвертована!).
    • 



Arduino має внутрішні pull-up резистори (≈20–50 кОм): pinMode(2, INPUT_PULLUP); — і зовнішній резистор не потрібен.

Повний приклад: кнопка керує світлодіодом


void setup() {
  pinMode(2, INPUT_PULLUP);  // кнопка
  pinMode(13, OUTPUT);       // світлодіод
}
void loop() {
  if (digitalRead(2) == LOW) {   // натиснута (pull-up!)
    digitalWrite(13, HIGH);
  } else {
    digitalWrite(13, LOW);
  }
}
